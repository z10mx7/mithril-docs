# Configuration

<PageStatus value="shipped">
`config.Config` is the single source of truth: this page lists every variable it reads.
</PageStatus>

Mithril reads configuration from the environment. In development, a `.env` file in the working directory is merged first; variables already set in the real environment always win, even if they're empty.

```go
cfg, err := config.FromEnv()   // what app.New does for you
```

## Variables

| Variable | Default | Description |
| --- | --- | --- |
| `APP_NAME` | `mithril` | Shown in the OpenAPI title, logs and admin panel |
| `APP_ENV` | *(unset = production)* | `development`, `dev`, `local`, `test` or `testing` enable development behaviour. **Anything else, including unset, is treated as production.** |
| `PORT` | `4000` | HTTP port |
| `JWT_SECRET` | — | Required outside development: at least 32 bytes, and not a published placeholder. In development an empty value gets a random secret per process. |
| `DATABASE_URL` | — | PostgreSQL URL. Takes precedence over `DB_*`. |
| `DB_HOST` `DB_PORT` `DB_USER` `DB_PASSWORD` `DB_NAME` `DB_SSLMODE` | — / `5432` / `postgres` / — / `mithril` / `disable` | Used when `DATABASE_URL` is empty and `DB_HOST` is set. Credentials are URL-escaped, so any password works. |
| `CORS_ORIGINS` | `http://localhost:3000,http://localhost:4000` | Comma-separated allowed origins |
| `ENABLE_REGISTER` | `false` | Allow `POST /auth/register` |
| `ENABLE_HELMET` | `true` | Security headers |
| `ENABLE_COMPRESSION` | `false` | gzip / brotli responses |
| `ENABLE_ADMIN_PANEL` | `false` | Admin panel at `/admin` (also enabled by a `.admin-panel-enabled` file) |
| `ENABLE_DOCS` | `true` in development | Swagger UI at `/docs` (`/openapi.json` is always served) |
| `ENABLE_MONITOR` | `false` | `/monitor` dashboard, superusers only |
| `APP_TIMEZONE` / `TZ` | `UTC` | Process time zone (IANA name) |
| `DBMS_ADDR` | `127.0.0.1:5050` | Address for `go run . dbms` |
| `LOG_REQUESTS` | `errors` | `errors` (status ≥ 400), `all` or `none` |
| `TRUST_PROXY` / `PROXY_HEADER` | `true` / `X-Real-IP` | Client IP from the header, honoured only when the peer is loopback/private |
| `DB_MAX_CONNS` / `DB_MIN_CONNS` | 4 per CPU (10–50) / `2` | Connection pool size (`pool_max_conns` in the URL wins) |
| `READ_TIMEOUT` / `WRITE_TIMEOUT` / `IDLE_TIMEOUT` | `30s` / `30s` / `120s` | Go durations or seconds; `0` disables |
| `BODY_LIMIT` | `4194304` | Maximum request body in bytes |
| `PPROF_ADDR` | — | Private pprof listener (loopback only unless `PPROF_ALLOW_REMOTE=true`) |
| `PREFORK` | `false` | One process per CPU (Linux, stateless apps only) |
| `HIGH_THROUGHPUT` | `false` | Skip `Date` and default `Content-Type` headers |

See [Performance](/docs/core/performance) for what each setting buys.

Booleans accept `1`, `true`, `yes` and `on`.

## Generating a secret

```bash
openssl rand -base64 32
```

`mithril new` writes a random secret into your project's `.env` (mode 0600) and leaves `env.example` blank.

## Production checklist

- `APP_ENV=production` (or leave it unset). Startup fails if `JWT_SECRET` is weak or the database is unreachable.
- Set `CORS_ORIGINS` to your real front-end origins.
- Keep `ENABLE_DOCS` and `ENABLE_MONITOR` off unless you need them.
- Run `./app migrate up` as a release step before starting new instances.

## Using Config in code

```go
a := app.Must(app.New())
if a.Config.IsDevelopment() { /* ... */ }
```

In tests, skip the environment entirely:

```go
a, err := app.New(app.WithEnvFile(""), app.WithoutDatabase(), app.WithConfig(config.Config{
    AppName: "test", Env: "test", JWTSecret: "test-secret-test-secret-test-secret",
}))
```
