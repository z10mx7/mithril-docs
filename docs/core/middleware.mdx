# Middleware Stack

<PageStatus value="shipped">
The stack below ships today. CSRF, rate limiting and sessions are **planned**: see the end of this page.
</PageStatus>

`app.New` installs these Fiber v3 middlewares, in this order:

| # | Middleware | Configuration | Notes |
| --- | --- | --- | --- |
| 1 | Request ID | always on | Sets `X-Request-ID`; included in 500 responses and error logs |
| 2 | Recover | always on | A panic becomes a 500, never a crash |
| 3 | Logger | always on | `[time] status - METHOD path (ip) latency` |
| 4 | CORS | `CORS_ORIGINS` | Only the listed origins |
| 5 | Helmet | `ENABLE_HELMET` (default **on**) | Security headers (`X-Frame-Options`, `nosniff`, HSTS, …) |
| 6 | Compress | `ENABLE_COMPRESSION` | gzip / brotli |

Route groups add their own middleware:

| Group | Middleware |
| --- | --- |
| `/api/*` | Database available (else 503) → JWT (HS256 only) → access-token claims (refresh tokens rejected) |
| `/auth/logout`, `/auth/me`, `/auth/*-2fa` | JWT → access-token claims |
| `/admin/api/*` | Database → JWT → claims → `admin.access` or superuser; ACL changes also require a superuser |
| `/monitor` | JWT → claims → superuser (DB-checked) |

## Errors

Every error goes through one handler. `*api.Error` values are returned as-is. Anything else becomes:

```json
{ "error": "internal_error", "message": "internal server error", "request_id": "…" }
```

The real error is logged with the request ID. Clients never see SQL or stack traces.

## Permission middleware

```go
api.Get(a.API, "/reports", listReports, api.Op{Summary: "Reports"},
    a.RequirePermission("reports.view"))

a.Fiber.Post("/api/maintenance", a.RequireSuperuser(), runMaintenance)
```

Both resolve the ACL service on each request, so they work even if the database connects after startup. The `acl` package also provides `RequireRole`, `RequireAnyPermission` and `RequireAdminAccess` for use with a known `*acl.Service`.

## Custom middleware

Install global middleware with `app.WithMiddleware`. It runs after the built-in stack and **before every route**:

```go
a := app.Must(app.New(
    app.WithMigrations(migrations, "migrations"),
    app.WithMiddleware(func(c fiber.Ctx) error {
        start := time.Now()
        err := c.Next()
        c.Set("Server-Timing", fmt.Sprintf("app;dur=%d", time.Since(start).Milliseconds()))
        return err
    }),
))
```

<Note type="warning">
Don't use `a.Fiber.Use(...)` for global middleware after `app.New`. Fiber runs handlers in registration order, so it
would skip every route that was already registered (the built-in routes and any resources).
</Note>

For route-specific middleware, pass it as the last arguments of `api.Get/Post/...` (it runs before the handler) or use `a.API.Group("/v2", mw)`.

Any [Fiber middleware](https://docs.gofiber.io/category/-middleware) works. For example, rate-limit logins today:

```go
import "github.com/gofiber/fiber/v3/middleware/limiter"

app.WithMiddleware(limiter.New(limiter.Config{
    Max: 10, Expiration: time.Minute,
    Next: func(c fiber.Ctx) bool { return c.Path() != "/auth/login" }, // only limit /auth/login
}))
```
