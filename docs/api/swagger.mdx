# OpenAPI & Swagger UI

<PageStatus value="beta">
Generated at runtime from Go types since v1.2. It replaces the AI-generated `make swagger` from 1.1.
</PageStatus>

Mithril builds the OpenAPI 3.1 document **from your code** while the app starts. There are no annotations to keep in sync, no generation step and no third-party service: the spec is deterministic, works offline and can't drift from the handlers.

| Where | What |
| --- | --- |
| `GET /openapi.json` | The live document |
| `GET /docs` | Swagger UI (on by default in development; `ENABLE_DOCS=true` elsewhere) |
| `go run . openapi -o openapi.json` | Write the document to a file (CI, client generation) |

## What is documented automatically

- **Resources:** every [resource](/docs/core/resources) adds list/create/get/update/delete operations with a component schema. Server-managed fields are marked `readOnly`, and required fields come from `validate:"required"`.
- **Typed handlers:** `api.Get/Post/Put/Patch/Delete` derive path and query parameters, the request body and the response from their `In`/`Out` types (see [Request Validation](/docs/api/validation)).
- **Built-in routes:** `/auth/*` and `/api/users/*`, including the bearer-token security scheme.

## How Go types map to schemas

| Go | Schema |
| --- | --- |
| `string`, `bool`, `int*`, `float*` | `string`, `boolean`, `integer`, `number` |
| `time.Time` | `string` / `date-time` |
| `uuid.UUID` | `string` / `uuid` |
| `[]T`, `map[string]T` | `array`, `object` with `additionalProperties` |
| `*T` | nullable (`["string", "null"]`) |
| named structs | `#/components/schemas/<Package><Name>` |

Tags that add detail:

```go
type CreateOrderIn struct {
    SKU      string `json:"sku" validate:"required,max=32" doc:"Stock keeping unit" example:"MUG-01"`
    Quantity int    `json:"quantity" validate:"required,min=1,max=99"`
    Email    string `json:"email" validate:"email"`         // format: email
    Size     string `json:"size" validate:"oneof=S M L"`    // enum
}
```

`min`/`max` become `minLength`/`maxLength` on strings and `minimum`/`maximum` on numbers.

## Generating clients

```bash
go run . openapi -o openapi.json
npx @openapitools/openapi-generator-cli generate -i openapi.json -g typescript-fetch -o web/src/api
```

## Programmatic access

```go
a := app.Must(app.New())
b, _ := json.Marshal(a.Doc)          // *openapi.Document
fmt.Println(a.Doc.Operations())      // ["GET /api/posts", "POST /api/posts", ...]
```

To document an untyped Fiber route, call `a.Doc.AddOperation(method, path, openapi.Operation{...})`.

## Notes

- Swagger UI loads its JavaScript and CSS from jsDelivr (pinned `swagger-ui-dist` version). In locked-down environments, set `ENABLE_DOCS=false` and serve only `/openapi.json`.
- `/openapi.json` is public, like most published API specs. If your API surface is sensitive, put a proxy rule in front of it.
