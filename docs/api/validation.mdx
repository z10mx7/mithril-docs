# Typed Handlers & Validation

<PageStatus value="beta">
The `api` package shipped in v1.2. More validation rules (e.g. regex, cross-field) are planned.
</PageStatus>

A typed handler receives a struct that Mithril has already **bound** (from path, query and JSON body) and **validated**, and returns a typed result. The same types drive the [OpenAPI document](/docs/api/swagger).

```go
package main

import (
    "github.com/gofiber/fiber/v3"
    "github.com/google/uuid"

    "github.com/mithril-framework/mithril/api"
    "github.com/mithril-framework/mithril/app"
)

type TransferIn struct {
    AccountID uuid.UUID `path:"id"`                                  // from /accounts/:id
    DryRun    bool      `query:"dry_run"`                            // from ?dry_run=true
    Amount    int64     `json:"amount" validate:"required,min=1"`    // from the JSON body
    Currency  string    `json:"currency" validate:"required,oneof=EUR USD"`
    Note      string    `json:"note" validate:"max=140"`
}

type TransferOut struct {
    ID     uuid.UUID `json:"id"`
    Status string    `json:"status" example:"pending"`
}

func routes(a *app.App) {
    api.Post(a.API, "/accounts/:id/transfers", func(c fiber.Ctx, in *TransferIn) (*TransferOut, error) {
        if in.DryRun {
            return &TransferOut{Status: "validated"}, nil
        }
        // ... business logic ...
        return &TransferOut{ID: uuid.New(), Status: "pending"}, nil
    }, api.Op{Summary: "Create a transfer", Tags: []string{"accounts"}})
}
```

## Routers

| Router | Prefix | Auth |
| --- | --- | --- |
| `a.API` | `/api` | Access token required (refresh tokens are rejected). Answers 503 while the database is down. |
| `a.Public` | `/` | None |
| `r.Group("/v2", middleware...)` | nested | Inherits the parent's |

Add permission checks as middleware: `api.Get(a.API, "/reports", h, api.Op{}, a.RequirePermission("reports.view"))`.

## Binding rules

- `path:"name"` fields are parsed from the URL (`string`, integers, `bool`, floats, `uuid.UUID`, or any `encoding.TextUnmarshaler`). A bad value returns **400**.
- `query:"name"` fields are bound from the query string.
- Every other exported field with a `json` tag comes from the JSON body (`POST`, `PUT`, `PATCH`). The body can't overwrite path or query fields.
- Use `*api.Empty` as the input or output type when there is nothing to bind or return. An `Empty` output answers **204**.

## Validation rules

| Rule | Strings | Numbers | Slices / maps |
| --- | --- | --- | --- |
| `required` | not empty | not zero | not empty |
| `min=N`, `max=N` | length in characters | value | number of items |
| `email`, `url`, `uuid` | format | — | — |
| `oneof=a b c` | one of the values | one of the values | — |

Pointer fields are optional unless `required`. A failed validation returns **422**:

```json
{
  "error": "validation_error",
  "message": "validation failed",
  "fields": [
    { "field": "amount", "rule": "min", "message": "amount must be at least 1" },
    { "field": "currency", "rule": "oneof", "message": "currency must be one of: EUR USD" }
  ]
}
```

## Errors

Return an `*api.Error` to control the response; any other error becomes a generic 500. Its details are logged with the request ID and never sent to the client.

```go
return nil, api.ErrNotFound                       // 404 not_found
return nil, api.ErrForbidden                      // 403 forbidden
return nil, api.BadRequest("account is frozen")   // 400 bad_request
return nil, api.Errorf(409, "conflict", "transfer %s already exists", id)
```

## Success status codes

`POST` answers **201**, handlers returning `*api.Empty` answer **204**, and everything else **200**. Override with `api.Op{Status: 202}`.
