# Welcome to Mithril

Mithril is a batteries-included, AI-friendly Go web framework built on [Fiber](https://gofiber.io). It brings the productivity of Django and Laravel (admin panel, RBAC, migrations, generators) and FastAPI's typed, self-documenting endpoints to Go, as a library you import.

```go
type Post struct {
    ID        uuid.UUID `json:"id"`
    Title     string    `json:"title" validate:"required,max=200"`
    Body      string    `json:"body" mithril:"text"`
    AuthorID  uuid.UUID `json:"author_id" mithril:"owner"`
    CreatedAt time.Time `json:"created_at"`
    UpdatedAt time.Time `json:"updated_at"`
}

func main() {
    a := app.Must(app.New(app.WithMigrations(migrations, "migrations")))
    a.Register(resource.Define[Post](resource.Options{Name: "posts"}))
    app.Main(a) // serve, or: migrate up | routes | openapi | createsuperuser | mcp
}
```

That's a validated, paginated CRUD API under `/api/posts` with JWT auth, ownership-aware permissions, an OpenAPI 3.1 document, Swagger UI and an admin panel page, all in one self-contained binary.

Each docs page is labelled <Status value="shipped" />, <Status value="beta" /> or <Status value="planned" />. The [Feature Status](/docs/getting-started/feature-status) page has the full list.

## How it compares

| | Mithril | Gin / Echo / Fiber |
| --- | --- | --- |
| HTTP engine | Fiber v3 (fasthttp) | — |
| CRUD from a struct | Yes | Manual |
| OpenAPI | Generated from types | Annotations / manual |
| Auth + RBAC + admin | Built in | Manual |
| Migrations | Embedded goose | Manual |
| AI agent tooling (MCP) | Built in | — |
