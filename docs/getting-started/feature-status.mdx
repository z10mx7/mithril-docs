# Feature Status

Every page in these docs carries one of three labels:

| Label | Meaning |
| --- | --- |
| <Status value="shipped" /> | In the current release (v1.3) and covered by tests. |
| <Status value="beta" /> | Available, but the API may change before 2.0. Feedback welcome. |
| <Status value="planned" /> | Not implemented yet. Code on that page shows the intended design, not something you can import today. |
