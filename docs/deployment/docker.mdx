# Docker & Single Binary

<PageStatus value="beta">
Single-binary builds (embedded migrations, views, assets and admin UI) shipped in v1.2.
</PageStatus>

A Mithril binary contains everything it needs: the core and app migrations, the admin panel UI, and any views and static files you pass with `app.WithViews` / `app.WithStatic`. Copy the binary anywhere and run it.

```bash
CGO_ENABLED=0 go build -trimpath -o bin/shop .
scp bin/shop server:/srv/shop/
ssh server 'cd /srv/shop && ./shop migrate up && ./shop serve'
```

## Container image

Projects created with `mithril new` include this Dockerfile:

```dockerfile
FROM golang:1.26-alpine AS build
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o /out/app .

FROM gcr.io/distroless/static-debian12:nonroot
COPY --from=build /out/app /app
ENV APP_ENV=production PORT=4000
EXPOSE 4000
USER nonroot
ENTRYPOINT ["/app"]
```

```bash
docker build -t shop .
docker run --rm --env-file .env shop migrate up      # release step
docker run --rm -p 4000:4000 --env-file .env shop    # serve
```

The image runs as non-root with no shell. Use `/livez` and `/readyz` for orchestrator probes (`/readyz` also checks the database).

## Environment

At minimum, set:

```bash
APP_ENV=production
JWT_SECRET=<openssl rand -base64 32>
DATABASE_URL=postgres://user:pass@db:5432/shop?sslmode=require
CORS_ORIGINS=https://shop.example.com
```

See [Configuration](/docs/core/configuration) for everything else.

## Local PostgreSQL

`docker compose up -d postgres` starts the database defined in the project's `docker-compose.yml`, bound to `127.0.0.1:5432`.

## Framework repository

The framework repo's own Dockerfile builds the reference app the same way (Alpine runtime with a `wget` health check), and `make docker-build` / `make run-docker` wrap it. Its `infrastructure/docker-compose.services.yml` provides optional dev services (PostgreSQL, pgAdmin, Adminer, Redis, RabbitMQ, Kafka) through `make dc-up-<service>`.
