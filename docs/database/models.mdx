# Models

<PageStatus value="shipped">
Models are plain Go structs. Declarative CRUD on top of them is described in [Resources](/docs/core/resources) <Status value="beta" />.
</PageStatus>

Mithril has no ORM: a model is a struct whose tags describe its JSON and columns, and the migration defines the table.

```go
package models

type Product struct {
    ID        uuid.UUID `json:"id"`
    Name      string    `json:"name" validate:"required,max=255"`
    Price     float64   `json:"price"`
    OwnerID   uuid.UUID `json:"owner_id" mithril:"owner"`
    CreatedAt time.Time `json:"created_at"`
    UpdatedAt time.Time `json:"updated_at"`
}
```

## Three ways to use a model

| Approach | When |
| --- | --- |
| **[Resource](/docs/core/resources)**: `resource.Define[models.Product](...)` | Standard CRUD with permissions, OpenAPI and admin. Start here. |
| **Typed handler + pgx**: `a.DB().Query(...)` inside an `api.Get` handler | Custom queries, reports, joins |
| **Repository struct** wrapping `*pgxpool.Pool` | Shared query logic used by several handlers |

```go
api.Get(a.API, "/reports/cheap-products", func(c fiber.Ctx, _ *api.Empty) (*[]models.Product, error) {
    rows, err := a.DB().Query(c, `SELECT id, name, price, owner_id, created_at, updated_at
                                  FROM products WHERE price < 10 ORDER BY price`)
    if err != nil {
        return nil, err
    }
    items, err := pgx.CollectRows(rows, pgx.RowToStructByPos[models.Product])
    return &items, err
}, api.Op{Summary: "Products under 10"}, a.RequirePermission("products.view"))
```

## Built-in models

`database/models` contains `User`, `Role` and `Permission`, and `database/repositories` holds their repositories (`UserRepository`, `ACLRepository`). They are available as `a.Users()` and `a.ACL()`.
